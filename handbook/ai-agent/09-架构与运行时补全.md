## agent.arch.workflow：什么时候需要动态决策

**结论**：下一步能预先写清时先用 workflow；下一步依赖运行时未知事实、需要模型判断时再引入 Agent。

**案例**：每天从三张固定表计算销售报表，用模型决定取哪张表，导致偶尔漏掉退款数据。流程本来固定，动态选择引入了不必要的不确定性。相反，排查未知报错时，是否查日志、读配置或运行复现取决于上一轮证据。

**机制**：workflow 将路径和转移条件编进程序，模型可作为其中一个受约束步骤；Agent 把部分路径选择留给运行时推断。两者可组合，边界由决策是否可预定义决定。引入动态决策后要额外承担轨迹验证、预算、停止和恢复成本。[Anthropic 架构说明](https://www.anthropic.com/engineering/building-effective-agents)

**误解靶子**：业务步骤多，所以必须用多 Agent。步骤多只说明流程长，不说明路径未知。

**判据**：在看到本轮工具结果前，能否写出完备、可维护的下一步转移规则？能写出时优先确定性流程。

**自测**：为“审批规则固定、输入是自由文本”的报销流程划出唯一需要模型判断的边界。

## agent.runtime.durable：恢复的是任务，不是聊天

**结论**：长期任务需要持久化执行状态；恢复时仍要处理副作用已提交而 checkpoint 未写入的窗口。

**案例**：退款成功后进程退出，尚未来得及保存“步骤完成”。重启后按旧 checkpoint 再退款。模型完整记得计划也无法判断服务端是否已扣款。

**机制**：保存任务、步骤输入、外部操作标识和状态；每次尝试使用同一业务幂等键。任务租约控制执行权，外部写入还需去重或 fencing 防止旧执行者继续提交。恢复时先核对未知步骤结果，再推进。暂停审批是持久状态；部署升级需定义状态/schema 迁移，不能直接用新代码重放旧输入。运行时的重放能力不自动让任意外部接口获得 exactly-once。[Durable Task 官方资料](https://learn.microsoft.com/en-us/azure/durable-task/sdks/durable-task-for-ai-agents)

**误解靶子**：每一步后保存 JSON 文件就能保证不重复执行。保存前的外部副作用仍有崩溃窗口。

**判据**：在“外部成功、内部未记完成”处终止进程后，恢复能否得到唯一业务效果？

**自测**：只为这个崩溃窗口设计一条验收断言。具体后端实现继续读 [Go Agent 后端](../go-backend/06-Agent后端.md)。

## agent.protocol.interop：连得上之后还剩什么

**结论**：协议定义消息与能力表达；业务主体、授权范围、幂等与恢复仍需实现方约定和执行。

**案例**：两个服务都支持工具调用，但一个 `customer_id` 指全局客户号，另一个指租户内编号。JSON 都合法，结果却读错客户。换一个协议封装不会修复编号空间。

**机制**：分别核对传输/版本、消息/schema、身份/委托、业务语义四层。认证确定调用主体，不自动授予访问某对象的权限；能力声明也不证明所有实现支持同一扩展。协作任务需定义状态、工件、取消、重试和重复投递处理。MCP 与 A2A 解决的交互对象不同，不能把支持协议当成完整业务互操作。[MCP 版本规则](https://modelcontextprotocol.io/specification/versioning)、[A2A 规范入口](https://a2a-protocol.org/latest/specification/)

**误解靶子**：工具 schema 通过、OAuth 成功，调用就安全。对象归属与动作授权不由字段类型保证。

**判据**：收到一个格式合法但主体无权访问的对象 ID，执行前由哪一段确定性代码拒绝？

**自测**：为跨租户工具调用写出一个拒绝条件，不使用“模型应该知道”。

## agent.rag.evaluation：把检索失败拆开测

**结论**：检索系统需要分层证据，最终回答正确不能证明检索与引用都正确。

**案例**：回答来自模型已有知识，引用恰好指向无关段落。只看最终答案得满分，却不能证明更新政策后系统还会答对。

**机制**：冻结查询、文档版本、访问身份与标注证据。先检查可访问语料中有没有答案，再看召回候选是否包含证据、排序是否把证据送入上下文、生成是否受证据支持。Recall@k 要有已标注相关集合，MRR/nDCG 要说明排序标签；答案正确性与引用忠实度独立检查。评测加入无答案、相互冲突、过期事实与无权限文档；指标变化按同一批查询配对看，不能只比较两个总均值。[Contextual Retrieval](https://www.anthropic.com/news/contextual-retrieval)、[RAG 引用忠实性研究](https://dl.acm.org/doi/10.1145/3731120.3744592)

**误解靶子**：回答错了就换 embedding；候选里没有证据时，rerank 无法凭空补回证据。

**判据**：出错查询的支持证据第一次消失在哪一层？先修这一层，再验证下游效果。

**自测**：已知证据不在 top-50、生成只看重排后的 top-5，指定应先检查的一个环节。
