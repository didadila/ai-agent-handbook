# 题型练习索引

这是26点的检索与练习建议，不是逐题转载题面，也不声称每个扩展都在TOP101或热100。访问[力扣题库](https://leetcode.cn/problemset/)或[热题100](https://leetcode.cn/studyplan/top-100-liked/)、[牛客TOP101](https://www.nowcoder.com/exam/oj/ta?tpId=295)按题名检索；带“扩展”的条目并非牛客该题单收录声明。平台限制、题型与语言环境使用时再核对。

| 点 | 力扣练习线索（语言选Python3） | 牛客题型/扩展方向 | 首次目标 |
|---|---|---|---|
| `alg.python` | 输入输出与容器 | Python语言练习与在线编程模式 | 两行共享同一内层对象 |
| `alg.complexity` | 复杂度检查 | 规模与超时分析 | 说明每一步的工作与求和，不能按for层数猜 |
| `alg.sort` | 排序数组 | 二分查找/排序 | 解释相等key稳定性、原地/返回值与比较成本，区分排序前提及后续算法。 |
| `alg.hash` | 两数之和 | 哈希 | 说明扫描前字典只含历史下标，平均O(n)时间、O(n)辅助空间及哈希最坏边界。 |
| `alg.two-pointers` | 三数之和 | 双指针 | 能证明被排除集合不含答案 |
| `alg.window` | 无重复字符的最长子串 | 双指针/字符串 | 说明窗口不变量、max保单调、O(n)指针移动和O(字符集)空间。 |
| `alg.prefix` | 和为K的子数组 | 哈希/数组 | 区分历史空前缀和空子数组 |
| `alg.binary` | 搜索插入位置 | 二分查找 | 解释左右排除区与终止时位置的含义，不混用闭区间更新。 |
| `alg.matrix` | 岛屿数量 | DFS/BFS网格扩展 | 能定义邻接与访问时机，检查单行、单列、全0、全1及输入是否被改。 |
| `alg.linked` | 反转链表 / 环形链表 | 链表→反转链表/环入口 | 能在纸上追踪prev/current/following，不断链，覆盖空链和单节点。 |
| `alg.stack` | 有效括号 / 每日温度 | 堆栈队列 | 讲清何时能确定被弹元素的答案，辅助栈最坏O(n)。 |
| `alg.heap` | 数组中的第K个最大元素 | 堆栈队列→最小的K个数 | 能说清堆内集合与阈值含义，不把heappushpop和heapreplace的空堆/顺序语义混淆。 |
| `alg.trie` | 实现Trie | 字符串前缀专题扩展 | 区分路径存在与词终止，能处理空词、重复词和含特殊字符的词。 |
| `alg.tree` | 二叉树的层序遍历 | 二叉树→层序遍历 | 解释队列本轮/下一轮边界，能用显式栈替换深递归。 |
| `alg.bst` | 验证二叉搜索树 | 二叉树→判断搜索树 | 能携带祖先边界、处理空树与极端整数，不使用固定32位哨兵误判。 |
| `alg.graph` | 腐烂的橘子 / 无权图最短步数 | 二叉树/递归与图专题扩展 | 讲清层次单调、不把visited的图搜索规则套到允许不同路径重访的回溯。 |
| `alg.topo` | 课程表 | 有向依赖专题扩展 | 说明就绪集合含义与完成计数，不把任意DFS访问顺序当拓扑序。 |
| `alg.union` | 省份数量 / 冗余连接 | 连通性专题扩展 | 能区分连通关系与路径本身，重复union不减少连通块数。 |
| `alg.shortest` | 网络延迟时间 | 加权图专题扩展 | 区分发现与确定、旧堆项与当前最优，说明负权破坏证明。 |
| `alg.backtracking` | 子集II / 全排列 | 递归/回溯 | 能区分同层与同路径去重、选择/撤销配对以及输出规模成本。 |
| `alg.dp` | 零钱兑换 | 动态规划→兑换零钱 | 说明状态与哨兵，不能只背方程 |
| `alg.knapsack` | 分割等和子集 | 动态规划→背包专题 | 用状态来源解释倒序，不把方向当口诀，区分恰好/至多和0/1/完全。 |
| `alg.sequence` | 最长递增子序列 / 最长公共子序列 | 动态规划→最长公共子序列 | 区分状态、长度与路径，解释left/right二分对应严格性。 |
| `alg.greedy` | 跳跃游戏 | 贪心算法 | 能说明何种局部选择可安全保留 |
| `alg.intervals` | 合并区间 | 贪心/区间专题 | 定义端点语义并证明扫描不遗漏，区分并集与最多活动数。 |
| `alg.bits` | 只出现一次的数字 | 位运算专题扩展 | 陈述出现次数假设、整数位宽与符号边界，不能声称任意整数操作永远O(1)。 |

建议每点先用正文构造题理解机制，再在平台独立写一个变体；答对题号不自动覆盖整个知识点。记录时只存自己实际做过的题和证据，不把题单勾选、运行一遍或抄模板记为A。
