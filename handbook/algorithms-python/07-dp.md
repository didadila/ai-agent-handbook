## alg.dp — 动态规划状态与转移

**入门简介。** 动态规划把可以复用的子问题答案记成状态，再按依赖关系计算更大的问题。

**生活比喻与边界。** 像把小订单报价记到账本再汇总；必须先定义每个数字代表什么，不能拿不兼容报价直接相加。

**结论与机制。** DP把重复子问题合并为状态。先写状态代表什么，再列转移、初值、计算顺序与答案位置；记忆化搜索只计算访问到的状态，递推要符合依赖顺序。最少硬币的dp[x]为凑到x的最少枚数，不能从默认0推导不可达状态。

| 判断维度 | 要点 |
|---|---|
| 适用与代价 | 最值、可行性与计数的单位元和不可达哨兵不同。时间是状态数乘转移代价。例子硬币可重复用，金额非负、币值为正，时间O(amount*币种数)，空间O(amount)。 |
| 构造反例 | 币值[2]金额3不可达，不能返回0；金额0则合法需要0枚。 |
| 掌握判据 | 说明状态与哨兵，不能只背方程；能用枚举小输入对拍。 |

**Python实现。** `min_coins`的完整函数如下；输入契约在上述机制中限定，不把这个模板套到未满足前提的题上。

```python
def min_coins(coins, amount):
    if amount < 0 or any(c <= 0 for c in coins):
        raise ValueError("positive coins and nonnegative amount required")
    dp = [0] + [amount + 1] * amount
    for total in range(1, amount + 1):
        for coin in coins:
            if coin <= total:
                dp[total] = min(dp[total], dp[total - coin] + 1)
    return dp[amount] if dp[amount] <= amount else -1
```

## alg.knapsack — 背包与循环方向

**入门简介。** 0/1背包在容量限制下选择物品，使价值最大；每件物品只能选零次或一次。

**生活比喻与边界。** 像把每件只拥有一份的行李装进箱子；本例重量为正、允许不装满，也不要求选满物品。

**结论与机制。** 0/1背包每件最多一次，压缩为一维后容量倒序，确保转移仍引用上一件物品之前的状态；完全背包可重复用，容量正序才能利用本轮结果。计数问题还要分组合与排列：物品外层通常避免重复枚举顺序，金额外层可能计入不同排列。

| 判断维度 | 要点 |
|---|---|
| 适用与代价 | 例子求不超过容量的最大价值，正整数重量，空集价值0；没有要求恰好装满。恰好装满须改不可达初值。O(物品数*容量)是伪多项式，容量的数值不是输入比特长度。 |
| 构造反例 | 只有一件重量1价值3、容量2，0/1答案3，正序更新会错误得到6。 |
| 掌握判据 | 用状态来源解释倒序，不把方向当口诀，区分恰好/至多和0/1/完全。 |

**Python实现。** `knapsack01`的完整函数如下；输入契约在上述机制中限定，不把这个模板套到未满足前提的题上。

```python
def knapsack01(weights, values, capacity):
    if len(weights) != len(values) or capacity < 0 or any(w <= 0 for w in weights):
        raise ValueError("matching arrays, positive weights, nonnegative capacity")
    dp = [0] * (capacity + 1)
    for weight, value in zip(weights, values):
        for c in range(capacity, weight - 1, -1):
            dp[c] = max(dp[c], dp[c - weight] + value)
    return dp[capacity]
```

## alg.sequence — 序列 DP：LIS、LCS 与编辑距离

**入门简介。** 子序列允许跳过元素但保留相对顺序；LIS求严格递增长度，LCS求两个序列共同子序列的最大长度。

**生活比喻与边界。** 像从原歌单删歌仍按原顺序播放；不能把留下的歌任意重排，也不要求它们原来挨着。

**结论与机制。** 子串连续、子序列可以跳过；不能混用状态。LIS可用O(n²)末尾状态或最小尾值数组加二分，严格递增用bisect_left，相等值替换而不扩长。tails[k]是长度k+1的最小尾值，不一定拼成输入的一条真实子序列。LCS在两前缀上按末字符相等/不等转移；编辑距离还需插入/删除/替换三类代价。

| 判断维度 | 要点 |
|---|---|
| 适用与代价 | LIS长度例子O(n log n)时间O(n)空间；恢复路径另存前驱。LCS滚动数组要保存旧对角，空间压缩不能覆盖仍要使用的状态。最长回文子串还要处理区间依赖方向。 |
| 构造反例 | [2,2,2]严格LIS长度1；非降子序列才可把相等值延长。 |
| 掌握判据 | 区分状态、长度与路径，解释left/right二分对应严格性。 |

**Python实现。** `lis_length`的完整函数如下；输入契约在上述机制中限定，不把这个模板套到未满足前提的题上。

```python
def lis_length(nums):
    tails = []
    for x in nums:
        pos = bisect_left(tails, x)
        if pos == len(tails):
            tails.append(x)
        else:
            tails[pos] = x
    return len(tails)

def lcs_length(a, b):
    if len(b) > len(a):
        a, b = b, a
    dp = [0] * (len(b) + 1)
    for x in a:
        diagonal = 0
        for j, y in enumerate(b, 1):
            old = dp[j]
            dp[j] = diagonal + 1 if x == y else max(dp[j], dp[j - 1])
            diagonal = old
    return dp[-1]
```
