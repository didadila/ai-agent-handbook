### 结论
四类记忆对象是诊断视角，不是绝对真值或必经流水线；dreaming是记忆整理，不是第五层或权重训练。

### 机制
| 对象 | 机制与边界 |
|---|---|
| transcript（原始事件记录） | 只证明当时记录了什么，不保证其中断言真实，也不代表当前授权；执行结果仍需核对执行账本与必要的外部状态。 |
| notes / representation / injected context | 分别是选择性笔记、组织化表示（如主题或索引）、本轮实际送入模型的内容；不必串行走完，原始事件也可直接选入上下文。派生物须保留来源、作用域、版本与失效关系。 |
| dreaming | 在交互间整理、纠错和提炼既有记忆，不是训练权重；猜测不能静默升为事实或扩大权限，变更应可复核、版本化、可回滚，收益需独立任务验证。 |
| 留存与删除 | 不必永久保留所有对话：按目的、授权、最小采集与留存期限处理，凭证不入日志；删除或撤权须传播到笔记、表示、缓存、摘要及未来注入。完整教材未安装，本轮使用[包内参考](references/engineering-learning.md)。 |
