### 结论
记忆分层区分信息形态与使用边界，不是必走流水线；完整案例教材未安装，本轮用包内参考讲解。

### 机制
| 对象 | 作用与边界 |
|---|---|
| transcript | 记录“当时说过、工具返回过什么”，是追溯依据，不是绝对事实真值：原话可能错误，结果可能过期。 |
| notes / representation / injected context | notes 是筛选出的笔记；representation 是便于存储、检索的表示，如结构化记录或向量；injected context 是本轮实际交给模型的内容。三者不必串行走完，可直接取原文或笔记，也可按需检索表示；存入不等于召回，召回不等于被遵守。 |
| dreaming | 通常指后台整理、反思、合并与纠错过程，可更新笔记或表示；不是固定第五层，也不等于训练模型权重。 |
| 保留与纠错 | 不必永远保存全部原始对话：按授权、用途与期限选择性保留必要证据，并记录来源、有效期及覆盖关系；删除须传播到摘要、派生表示、索引、缓存及后续上下文，审计可只留不含原文的状态。 |
