### 机制
| 边界 | 纠正 |
|---|---|
| Python 实现与构建 | 不能说所有 Python 都有 GIL；CPython 的常规 GIL 构建与可选 free-threaded 构建要区分，后者不能当作所有构建的默认。 |
| `asyncio.to_thread` | 把函数交给线程执行，避免该函数直接阻塞事件循环；不等于自动获得 CPU 多核并行。 |
| GIL 开启、纯 Python CPU 计算 | 多个线程不能同时执行 Python 字节码；要利用多核，通常考虑多进程，并承担进程通信等开销。 |
| free-threaded 构建 | 还要确认运行时 GIL 是否关闭；扩展可能重新启用它。关闭后线程可并行执行，但不保证加速，也不免除共享数据同步。 |
