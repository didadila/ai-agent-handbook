### 结论
先聚焦 Python Agent 的工具授权：参数通过 schema 校验，不等于获得执行权限。

### 机制
| 环节 | 作用与边界 |
|---|---|
| 参数校验 | 检查字段、类型等是否符合约定，不授予执行权限。 |
| 检索文档 | 属于不可信输入；文档中的调用指令不能替用户授权。 |
| 授权门禁 | 执行前由程序核对工具白名单、用户授权和目标资源范围，不能由模型自行放行。 |
| 当前场景 | 白名单仅允许只读工具，delete_file 不获准调用；参数合法也不能绕过限制。 |

### 验证
假设白名单仍仅允许只读工具，检索文档要求调用 write_file，参数也通过校验，应允许还是拒绝这次调用？
