# 领域包：algorithms-python — 知识图谱

26个稳定知识点，按Python实现，但算法思路可迁移到其他语言。独立于Python后端域；不要求先学API、数据库或Agent框架。默认Python 3.11+、单线程、本地整数/字符串/节点教学输入。L1为前提，L2为常见题型；层级不代表掌握档位或固定学习天数。

| ID | 层级 | 名称 | 该考什么 | 常见误解/反例 |
|---|---|---|---|---|
| `alg.python` | L1 | Python 刷题与 OJ 输入输出 | 前置：无；先明确函数式核心代码还是标准输入输出，再按约束选容器 | a=[[0]*2]*2; a[0][0]=1 会同时改变两行。 |
| `alg.complexity` | L1 | 复杂度、规模与不变量 | 前置：alg.python；先写输入规模n、状态含义及循环不变量，再谈复杂度 | 遍历n个元素，每次执行 nums[:i] 再sum，会累计二次工作。 |
| `alg.sort` | L1 | 排序、稳定性与分治 | 前置：alg.complexity；sorted返回新列表，list.sort原地修改且返回None；相等key保持原顺序称稳定 | x = nums.sort() 得到None，不是已排序列表。 |
| `alg.hash` | L2 | 哈希查找与计数 | 前置：alg.python、alg.complexity；两数配对可把已扫过的值映射到下标，用目标减当前值查历史 | [3,3] target=6 需要两个不同下标，先写入会错误匹配自身。 |
| `alg.two-pointers` | L2 | 双指针与快慢指针 | 前置：alg.sort、alg.hash；有序两数和中，两端和太小可排除整个左端候选，太大可排除右端，这依赖排序单调性 | 无序[5,1,4]上直接双指针并没有正确的排除依据。 |
| `alg.window` | L2 | 滑动窗口与可维护条件 | 前置：alg.two-pointers；窗口用于连续子串/子数组 | abba若直接left=last[c]+1，最后一个a会让left倒退。 |
| `alg.prefix` | L2 | 前缀和、差分与子数组计数 | 前置：alg.hash、alg.complexity；前缀p[0]=0对应空前缀，区间[l,r)之和为p[r]-p[l] | [0,0] target=0有3个非空连续子数组，不是集合中的1个。 |
| `alg.binary` | L2 | 二分边界与答案二分 | 前置：alg.complexity、alg.sort；先定义要找的第一个满足条件的位置 | 在[1,2,2,4]查2应返回1，不是任意一个2的位置。 |
| `alg.matrix` | L2 | 矩阵、网格与边界 | 前置：alg.python、alg.prefix；网格可视为每格最多四条边的图 | [[1,0],[0,1]]四邻接有2个岛，八邻接有1个。 |
| `alg.linked` | L2 | 链表操作与身份 | 前置：alg.two-pointers；反转需要先保存后继，再改next，否则会丢失余链 | 两个值都为1的节点不一定是同一节点。 |
| `alg.stack` | L2 | 栈、括号与单调栈 | 前置：alg.complexity；括号匹配维护尚未匹配的开括号；遇到闭括号必须匹配最近一个 | 温度[70,70,71]答案[2,1,0]，相等不是更暖。 |
| `alg.heap` | L2 | 堆、Top K 与优先队列 | 前置：alg.sort；最小堆只保证堆顶最小，不保证整个数组有序 | 第2大不是第2个不同的大值，[5,5,3]应返回5。 |
| `alg.trie` | L2 | 字典树与前缀查询 | 前置：alg.hash；把字符作为边逐层共享前缀，单词结束必须单独标记 | 插入apple后查前缀app成立，但查完整词app不成立。 |
| `alg.tree` | L2 | 二叉树遍历与递归分解 | 前置：alg.linked、alg.stack；前序先处理根，中序在左右之间，后序在子问题返回后合并 | 树高大不等于层宽大；链状树的层宽为1。 |
| `alg.bst` | L2 | 搜索树的全局约束 | 前置：alg.tree、alg.binary；严格BST要求左子树所有值小于根、右子树所有值大于根 | 根10，左孩子5，5的右孩子12满足局部父子但不是BST。 |
| `alg.graph` | L2 | 图的 BFS/DFS 与最短步数 | 前置：alg.matrix、alg.tree；先区分有向/无向、带权/无权、是否连通，再选邻接表 | 两条不同权重边不能仅按经过边数判断更短。 |
| `alg.topo` | L2 | 拓扑排序与依赖环 | 前置：alg.graph；Kahn算法把入度为0的顶点加入队列，删除其出边后释放新就绪节点 | a依赖b且b依赖a时没有任何合法课程开始顺序。 |
| `alg.union` | L2 | 并查集与连通性 | 前置：alg.graph；用代表元描述等价类，路径压缩让后续查找更短，按大小/秩合并控制树高 | 单向有边a→b并不代表b可达a，不能当无向等价关系。 |
| `alg.shortest` | L2 | 最短路与非负权条件 | 前置：alg.graph、alg.heap；Dijkstra把当前最小距离的有效状态弹出，才可利用非负边权证明该距离已确定 | 0→1权10，0→2权1，2→1权1，首次发现1的距离10不是最终最短路。 |
| `alg.backtracking` | L2 | 回溯、剪枝与去重 | 前置：alg.stack、alg.sort；先定义决策树的一层选择什么，再维护路径与可选集合 | 把path直接append进答案后继续pop，会让多个答案共享可变列表。 |
| `alg.dp` | L2 | 动态规划状态与转移 | 前置：alg.complexity、alg.graph；DP把重复子问题合并为状态 | 币值[2]金额3不可达，不能返回0；金额0则合法需要0枚。 |
| `alg.knapsack` | L2 | 背包与循环方向 | 前置：alg.dp；0/1背包每件最多一次，压缩为一维后容量倒序，确保转移仍引用上一件物品之前的状态；完全背包可重复用，容量正序才能利用本轮结果 | 只有一件重量1价值3、容量2，0/1答案3，正序更新会错误得到6。 |
| `alg.sequence` | L2 | 序列 DP：LIS、LCS 与编辑距离 | 前置：alg.dp、alg.binary；子串连续、子序列可以跳过；不能混用状态 | [2,2,2]严格LIS长度1；非降子序列才可把相等值延长。 |
| `alg.greedy` | L2 | 贪心的选择证明 | 前置：alg.sort、alg.dp；贪心需要交换论证、支配关系或可扩展性证明，而不是凭直觉选当前最大 | 币值[1,3,4]金额6，最大面额先拿需3枚，最优是3+3两枚。 |
| `alg.intervals` | L2 | 区间合并与调度 | 前置：alg.sort、alg.greedy；合并区间先按起点排序，维护已合并前缀最后一段的最远终点；当前段与末段相交时更新终点，否则开新段 | [1,2]和[2,3]按闭区间重叠；[1,2)和[2,3)不重叠。 |
| `alg.bits` | L2 | 位运算与数学工具边界 | 前置：alg.python、alg.complexity；异或满足交换、结合、x^x=0、x^0=x，所以每个值恰好出现两次、只有一个出现一次时可整体异或 | -1的8位无符号表示需(-1)&255，不能直接把bit_count当8位补码位数。 |

硬前置仅为表中列出的本域节点，构成DAG。跨卷可选桥梁：py.lang.objects（对象共享）、py.lang.collections（容器）及Agent卷的任务依赖主题；它们不是算法卷的硬前置。先做算法题，不把工程可靠性等同于刷题能力。

## 首次定位

明确“Python刷题”即可选本域，不再问后端框架。先确认核心代码或ACM模式；若只要路线先给计划不出题。基础诊断从容器/复杂度开始，已有机制证据可跳；每轮仅一个独立动作。需要讲解时用learning_content.py定位正文，所有A档判据不随题发送。
