# 短期项目式学习协议

## 目标与边界

将“几天学会 Python 后端 + Agent”转成可验收的小目标：能实现并解释一个异步知识检索任务服务的主要路径和关键故障。五天是学习安排，不是精通承诺、线上交付保证或自动定时任务。默认计划假设每天3–4小时、已有编程经验；不据此假定语言和数据库已经掌握。

保留单题、短补课、停止条件和个人档案的本地边界。这里改变的是学习节奏，不降低A档标准，也不新增共享成绩字段。

## 入口与按需读取

1. 语言明确为 Python 时选 `python-backend`，读该域 map；不要因出现 Agent、Redis 或消息队列跳到其他实现域。用户明确要求语言无关 Agent 设计时才转 `ai-agent`。
2. 完整仓库读 `handbook/python-backend/sprint-5-days.md`；单个点用 `scripts/learning_content.py --domain python-backend --point <ID>` 定位并读取正文。存储选型读第四章，分发与重启读第五章，工具安全读第六章。
3. 独立安装且无 handbook 时说明限制，用包内 map/questions/sources 给概念练习；不编造实验路径、HTTP服务、执行结果或教材行号。
4. 用户已有明确时长、背景、目标则直接使用。只有影响路线且无法合理假设的缺项才问一个问题；“每天3–4小时”可明示为可调整假设，不反复询问已经说明的语言。

## 计划请求

用户只要求路线时，给一张不超过五内容行的表：每天主题、一个最小交付物、验收证据。安排计划不强行追加诊断题，也不预填个人成绩。

|天|必做主线|选读/扩展|
|---|---|---|
|1|对象/默认参数与资源生命周期，建立可复现测试入口|集合复杂度、类型协议、环境锁定|
|2|异步阻塞边界与API输入契约，验证超时和取消|背压、进程池、SSE事件契约|
|3|SQL模型/事务/唯一约束，任务与检索元数据可重开读取|索引、Redis、对象存储、向量检索，先作选型不全安装|
|4|重复提交/消费、租约接管与旧worker提交拒绝|Outbox通知、定时任务、Celery与多副本扩展|
|5|只读工具白名单、持久恢复、确定性回归|真实模型评测、观测、反向代理/容器发布与恢复演练|

评测运营、长任务harness与记忆分层的进阶选读见 `engineering-learning.md` 和 Python教材第6章；不因教材补全自动扩成五天必学或30点批量验收。六个新增离线教学测试也不代表真实模型、生产记忆或通用回放已交付。

详细知识点归属以教材路线为准。Python语言语义 → 事件循环/资源生命周期 → 服务与存储 → 分发恢复 → Agent与交付是依赖主链；不能只因第4天到了就跳过还不会的事务。

## 开始与逐轮实战

用户说“开始”时，若没有已知起点，先从一个语言前置诊断开始；接住后再问并发，最后问恢复，不同一轮抛出三题。用户说“会Python基础”可用一个小变体确认，不要求重新背完整语法；用户明确说“先讲”则直接讲，不用诊断阻拦。

每个学习单元按以下节奏推进，各步骤可以占不同轮次：

- 定位一个真实缺口，或直接选用户指定机制。
- 按 `output-format.md` 给“结论／机制／验证”短补课。用户要求展开时才给长代码或深入解释。
- 布置一个最小代码改动或一个故障实验，只有一个可独立验收动作；不把“设计API、写数据库、配Redis、部署、解释重试”绑成一题。
- 等待用户的代码/测试输出，或在其明确授权范围内本地执行验证；没有运行记录只称建议/预期，不称实测。
- 验收后可换一个机制问题；该轮只一个动作。达到目标或用户要求换点/结束就停。

代码示例与测试是公共学习材料，默认只运行本地合成数据。不要把配置云服务、安装依赖、调用付费模型、访问生产数据、发布服务或写个人档案当成计划附带授权。服务接口设计和CLI实验分别说明，CLI跑通不冒充HTTP/SSE服务已经验收。

## 四种证据，不能混记

|观察|能说明什么|不能说明什么|
|---|---|---|
|示例或用户代码跑通|该环境下最小路径可运行|30点全部掌握，或生产正确|
|故障输入通过|某个重放/取消/重启性质在测试范围成立|所有并发时序、外部效果恰好一次|
|未泄漏答案前独立解释|可按该知识点A/B/C/D判据评价|自动代表其他领域或所有关联点|
|延迟后新场景迁移|有更强独立理解证据|五天后永久掌握|

刚补课后的验证最多记讲解后接住，不直接判独立A。运行结果可在本地 sessions 总结中标“代码跑通／故障已验证／独立解释未验证／延迟迁移未验证”，但 progress 和 mistakes 沿用原表结构，只写实际发生的题目与答案；不因完成 day1 把关联6点全填A。不读取真实档案制作公开评测。

## 复习、存储和停止

到期错题仍优先；用户明确要新内容或换点时尊重选择，保留待复习项。保存前遵守 learning_state.py 的路径/权限预检，拒绝后不 chmod、不换路径绕过。计划“第几天”与下次复习绝对日期不是同一回事，没有排程不许声称已安排提醒。

收尾采用“状态／记录／入口”，只记录实际证据和一个下一步。未完成扩展说明未完成；不以缩短讲解隐藏前置缺口，也不在收尾临时塞进一整课。
