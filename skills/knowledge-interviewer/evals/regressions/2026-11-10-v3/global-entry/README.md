# 全局入口冒烟

## 协议

候选16例通过后，用户授权将现有Qoder软链原子替换为当前仓库Skill目录；旧工作副本未删除，旧目标仅保存在本机被Git忽略的备份中。两个全新执行体仅收到全局Skill路径、原话与合成夹具，不提供仓库Skill路径、rubric、历史结果或真实档案。

## 结果

2/2例、9/9条预声明判据满足。执行体观测到全局路径解析为当前仓库，补课满足固定三段、语义标题与标注假设的单题要求，路由未外露内部ID或预填成绩。实际入口与主Skill/配套资源身份另由check_skill_entry.py核验，结果见entry-check.json。

## 限制

这验证的是软链文件入口及新冷启动执行体读取，不是Qoder宿主进程的端到端调用，也不证明已打开会话的注册表/description缓存已经刷新。切换后在新会话加载；没有重启或干预正在运行的宿主。每例n=1且评审同族模型。
