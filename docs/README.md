# 项目设计与维护文档

docs解释学习系统如何组织、维护和验证；学具体技术从handbook或Skill进入。通常学习者读根README即可，维护者按问题选择下表。

|文档|回答的问题|读者|
|---|---|---|
|[目录架构](architecture.md)|为什么分这些目录，旧目录迁到哪里|贡献者与维护者|
|[学习系统设计](learning-system.md)|Skill如何用教材、题库与图解，还缺什么|学习者与维护者|
|[报告目录](reports/README.md)|哪次改动实际检查了什么，有哪些失败和限制|审查者与维护者|

reports是带日期的历史证据，不是另一套教材。相同日期可能有多个阶段报告，按具体范围阅读；最新报告也只覆盖明确列出的核验项，不能自动覆盖所有旧证据。当前学习规则以Skill和references为准，事实以相应sources及官方来源为准。
