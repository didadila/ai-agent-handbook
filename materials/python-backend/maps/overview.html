DAY 01 / 语言前置

对象、类型与可复现环境

先确认 Python 的对象模型和资源边界；会写业务代码可以少讲语法，不能跳过默认参数和共享可变状态。

  • 对象绑定、可变性 py.lang.objects
  • 集合选择与复杂度 py.lang.collections
  • 函数参数、闭包与默认值 py.lang.functions
  • 类型提示与运行时校验 py.lang.types
  • 异常、上下文管理与清理 py.lang.resources
  • 虚拟环境、依赖锁定与测试 py.lang.environment
阅读语言机制
DAY 02 / 异步前置

并发不等于 CPU 并行

以 Python 3.11+ 的结构化并发为教学基线；明确同步阻塞、取消传播与有界资源。

  • 事件循环与阻塞边界 py.async.eventloop
  • 超时、取消与 TaskGroup py.async.cancellation
  • 信号量、队列与背压 py.async.backpressure
  • 线程、进程与构建边界 py.async.execution
阅读异步机制
DAY 02 / 服务边界

一个请求，一条明确契约

FastAPI/Pydantic 是实现建议。HTTP 202 是受理，不代表完成；SSE 断流也不代表任务失败。

  • 输入/输出校验与授权 py.svc.contract
  • lifespan、连接池与关闭 py.svc.lifecycle
  • 幂等键、指纹与未知结果 py.svc.idempotency
  • 流式事件、游标与重放 py.svc.streaming
阅读 API 机制
DAY 03 / SQL 必做，其余按需扩展

存储分工，不全塞进 Redis

本地 SQLite 学持久化；多副本生产评估 PostgreSQL。缓存、对象和向量索引分别解决不同问题。

  • 数据模型、租户与迁移 py.data.model
  • 事务与会话生命周期 py.data.transactions
  • 索引与执行计划 py.data.indexes
  • Redis 缓存、一致性与失效 py.data.cache
  • 对象存储、元数据与签名权限 py.data.objects
  • 检索、证据与租户过滤 py.data.retrieval
阅读存储选型
DAY 04 / 持久任务

重启之后，谁继续执行？

队列交付与业务效果是两层。先验证重复提交和过期租约，再考虑 Celery、更多 worker 或定时触发。

  • 交付语义、重试与去重 py.jobs.delivery
  • 同库同事务 Outbox py.jobs.outbox
  • 租约、接管与旧 worker 栅栏 py.jobs.leases
  • 调度、重叠执行与时间 py.jobs.scheduling
阅读分发与恢复
DAY 05 / PYTHON × AGENT

工具有边界，轨迹有证据

先用只读替身验证确定性机制；真实模型必须另测检索质量、任务成功、成本和安全。

  • 工具白名单、schema 与当前授权 py.agent.tools
  • 状态机、checkpoint 与预算 py.agent.runtime
  • 轨迹回归、失败分类与模型评测 py.agent.evaluation
阅读 Agent 实现
DAY 05 / 交付扩展

从本地测试到上线门槛

请求流量、内容分发、任务分发分别设计。CI、回滚、迁移和恢复不以“容器启动了”代替验收。

  • 日志、指标、trace 与成本 py.ops.observability
  • 反向代理、多进程、容器与 CDN py.ops.deployment
  • 备份恢复、迁移与回滚 py.ops.recovery
阅读交付机制
