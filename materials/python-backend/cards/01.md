# 复习卡：任务服务的七个故障落点

这些是合成教学场景，不是用户错题。复习时只取一行的一个问题，不同时展开整张表。

|场景|先验证哪个边界|一个问题|关联ID|
|---|---|---|---|
|异步接口中同步请求阻塞|事件循环是否被同步I/O占住|为什么把函数改成async def仍可能卡住其他请求？|py.async.eventloop|
|请求超时，后台还在执行|取消传播与外部未知结果|客户端超时能证明下游操作没发生吗？|py.async.cancellation|
|同一key并发提交两次|唯一约束与请求指纹|两次先查询再插入为什么仍会重复创建？|py.svc.idempotency|
|缓存失效后任务消失|权威SQL与派生缓存|Redis缓存丢了后任务应从哪里恢复？|py.data.cache|
|SQL提交了但通知没发出|同库同事务Outbox|怎样消除提交任务与写通知记录之间的崩溃窗口？|py.jobs.outbox|
|worker超时被接管，旧worker又回来|租约token与提交条件|旧worker完成后为什么不能直接写成功状态？|py.jobs.leases|
|检索文本让Agent调用删除工具|不可信内容与当前授权|检索结果能授予工具执行权限吗？|py.agent.tools|

## 组件不是越多越好

|需求|第一选择（教学建议）|不能替代什么|
|---|---|---|
|任务状态/请求去重/租户关系|本地SQLite学习；多实例生产评估PostgreSQL|外部服务的幂等与对账|
|热点读取/短期派生值|按需要加Redis，TTL+容量限制|持久任务权威状态|
|文件/大对象|对象存储+SQL元数据，限定签名能力|数据库事务或对象访问授权|
|异步执行|先理解持久队列，再按规模评估Celery等|端到端业务恰好一次|
|语义检索|先建立证据与租户过滤，再评估向量索引|事实正确性与模型权限|
|流量/内容分发|反向代理/多worker；静态对象可用CDN|持久任务分发、checkpoint与授权|
