# 算法复习卡：先查前提

一次只取一行的一个问题，不把整表变成作答清单。

| 知识点 | 反例/缺口 | 最小检查 |
|---|---|---|
| `alg.python` | a=[[0]*2]*2; a[0][0]=1 会同时改变两行。 | 只写出空字符串交给read_pairs的结果。 |
| `alg.complexity` | 遍历n个元素，每次执行 nums[:i] 再sum，会累计二次工作。 | 只说明辅助空间统计是否应包含递归栈。 |
| `alg.sort` | x = nums.sort() 得到None，不是已排序列表。 | 只写出list.sort()的返回值。 |
| `alg.hash` | [3,3] target=6 需要两个不同下标，先写入会错误匹配自身。 | 只判断[0,0]能否用两个不同位置凑到0。 |
| `alg.two-pointers` | 无序[5,1,4]上直接双指针并没有正确的排除依据。 | 只写出空有序数组查找任意两数配对的结果。 |
| `alg.window` | abba若直接left=last[c]+1，最后一个a会让left倒退。 | 只写出空字符串的最长无重复子串长度。 |
| `alg.prefix` | [0,0] target=0有3个非空连续子数组，不是集合中的1个。 | 只写出空数组中和为0的非空子数组数。 |
| `alg.binary` | 在[1,2,2,4]查2应返回1，不是任意一个2的位置。 | 只写出lower_bound([],3)的结果。 |
| `alg.matrix` | [[1,0],[0,1]]四邻接有2个岛，八邻接有1个。 | 只判断空网格是否有岛。 |
| `alg.linked` | 两个值都为1的节点不一定是同一节点。 | 只写出空链反转的结果。 |
| `alg.stack` | 温度[70,70,71]答案[2,1,0]，相等不是更暖。 | 只判断空括号串是否匹配。 |
| `alg.heap` | 第2大不是第2个不同的大值，[5,5,3]应返回5。 | 只写出[5,5,3]的第2大。 |
| `alg.trie` | 插入apple后查前缀app成立，但查完整词app不成立。 | 只判断空Trie是否含空词。 |
| `alg.tree` | 树高大不等于层宽大；链状树的层宽为1。 | 只写出空树层序遍历结果。 |
| `alg.bst` | 根10，左孩子5，5的右孩子12满足局部父子但不是BST。 | 只判断空树在本卷约定下是否合法。 |
| `alg.graph` | 两条不同权重边不能仅按经过边数判断更短。 | 只说明不可达点的距离标记是什么。 |
| `alg.topo` | a依赖b且b依赖a时没有任何合法课程开始顺序。 | 只写出空有向图的拓扑序。 |
| `alg.union` | 单向有边a→b并不代表b可达a，不能当无向等价关系。 | 只判断重复合并同一连通块会否再减少块数。 |
| `alg.shortest` | 0→1权10，0→2权1，2→1权1，首次发现1的距离10不是最终最短路。 | 只判断Dijkstra能否直接用于负边。 |
| `alg.backtracking` | 把path直接append进答案后继续pop，会让多个答案共享可变列表。 | 只写出空集合的子集集合。 |
| `alg.dp` | 币值[2]金额3不可达，不能返回0；金额0则合法需要0枚。 | 只写出金额0的最少硬币数。 |
| `alg.knapsack` | 只有一件重量1价值3、容量2，0/1答案3，正序更新会错误得到6。 | 只判断0/1背包同一件能否重复选。 |
| `alg.sequence` | [2,2,2]严格LIS长度1；非降子序列才可把相等值延长。 | 只写出空数组的LIS长度。 |
| `alg.greedy` | 币值[1,3,4]金额6，最大面额先拿需3枚，最优是3+3两枚。 | 只写出[0]能否到达自身。 |
| `alg.intervals` | [1,2]和[2,3]按闭区间重叠；[1,2)和[2,3)不重叠。 | 只判断[1,1]是不是合法闭区间。 |
| `alg.bits` | -1的8位无符号表示需(-1)&255，不能直接把bit_count当8位补码位数。 | 只判断x^x是否等于0。 |
