Go 后端知识地图

从值的语义，到可恢复的任务运行时
按依赖顺序读，不要从第 6 章开始

1 · 值与错误

L1 · 语言核心
go.lang.value / error / interface
  • struct 拷贝，slice/map 共享底层数组
  • 零值不能表达「没传」→ *T / Null*
  • 错误是返回值：%w、errors.Is/As
  • typed nil 让判空失效
判据：这段代码会不会改到别人的数据？

4 · 数据与一致性

L2 · 数据层
go.data.tx / index / consistency
  • 一个业务动作一个事务，事务内不调网络
  • 索引是否生效只由 EXPLAIN 回答
  • 至少一次 + 幂等消费 + 分区键
  • Outbox 同库同事务，对账兜底
判据：消息重复两次，业务会怎样？

2 · 并发与生命周期

L1 · 语言核心
go.conc.goroutine / context / race / backpressure
  • 每个 goroutine 都要有退出条件与上限
  • context 是取消树，断一层就失效
  • 共享状态必须同步，-race 进 CI
  • 队列有界，满了必须拒绝或阻塞
判据：同时最多有多少个？谁在保证？

5 · 可观测性

L3 · 分布式
go.obs.log / trace / slo
  • 日志字段固定，错误只打一次
  • 指标看 P95/P99，不看均值
  • 每个外部调用一个 span
  • 告警按错误预算燃烧速度
判据：5 分钟内能不能定位到哪一段？

3 · 服务边界

L2 · 生产化
go.svc.timeout / pool / idempotency / shutdown
  • 每层超时递减，Server/Client 默认无超时
  • 池上限 × 副本数 ≤ DB 上限
  • 超时 ≠ 没执行，重试前先查状态
  • 先摘流量，再等在途，最后关依赖
判据：这个请求最坏要多久？谁保证？

6 · Agent 后端

L4 · Agent 后端
go.agent.gateway / runtime
  • 首 token 之后不能重放，只能中断
  • usage 可能缺失 → 估算 + 对账
  • 任务状态落库，租约接管失联 worker
  • 审批是持久化状态，不是弹窗
判据：kill -9 之后，这个任务会怎样？
全书一句话：「应该没事」不是判据，「谁在保证」才是。
先跑起来，再问失败；先写测试，再讲取舍
